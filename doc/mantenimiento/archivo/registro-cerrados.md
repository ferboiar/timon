# Registro: filas cerradas (archivo)

Archivo de consulta (DC-69), creado el 2026-11-19. Contiene, **sin cambios de texto**, las filas del
[registro de hallazgos](../registro-hallazgos.md) que constan corregidas o cerradas (con fecha o PR) y las
decisiones DC marcadas como sustituidas; DC-47 no está aquí porque sigue vigente. No se lee entero: se busca
el ID con `grep -n "^| F-12 " doc/mantenimiento/archivo/registro-cerrados.md`. Las filas abiertas, parciales o
dudosas y todas las decisiones vigentes siguen en las partes 1 a 3. La cabecera de cada tabla repite las
columnas de su sección original.
